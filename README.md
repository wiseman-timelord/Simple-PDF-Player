# Simple-PDF-Player
Status: Alpha; Working on it.

### Description
Its a WinAmp style player of PDFs, using, Kokoro for TTS and NiceGUI for GUI.

### Preview
![Image Missing](https://raw.githubusercontent.com/wiseman-timelord/Simple-PDF-Player/refs/heads/main/media/simple-pdf-player.jpg)

### Structure
```
.\Simple-PDF-Player.bat
.\installer.py
.\launcher.py
.\scripts\__init__.py
.\scripts\displays.py
.\scripts\speach.py
.\scripts\temporary.py
.\scripts\utility.py
```

### Requirements
- Python 3.12 - It may work on other versions of python however, I will not be testing.
- Windows 10 - It will likely work on windows 11. Obviously Windows 8.1 cannot install Python 3.12.
